# Sekiro: Shadows Die Twice Manual Archipelago
This manual is a hybrid of an item/shop/skill randomzier and manual archipelago. Most items, shops and skills are randomized and then a set list of randomized items are added to the manual archipelago. Key items are always included in the manual as they are required for logic and tracking. All archipelago locations have been replaced with a custom archipelago item and received items are granted by using the DLL Mod For Granting Items by HomoRadahn.
## Setting up a mutilworld
Run manual.bat from the Sekiro Manual folder. This will randomize the items, shops and skills in Sekiro, then write the sekrio_manual.apworld and install it. Once installed simply move the sekiro_manual.yaml to players folder and set up a world.
## Running the game
Run launch-sekiro_manual.bat from the Sekiro Manual folder. This will launch sekiro with randomized settings and replace the archipelago locations with a custom archipelago item
